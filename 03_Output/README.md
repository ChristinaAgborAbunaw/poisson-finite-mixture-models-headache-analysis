# Analysis Outputs

This folder contains the main numerical outputs generated during the Poisson finite mixture analysis.

Key outputs include:

- `descriptive_statistics.csv` — sample size, mean, variance, standard deviation, range, and variance-to-mean ratio.
- `model_comparison.csv` — AIC and BIC comparison for 2–5 component Poisson mixtures.
- `final_three_component_parameters.csv` — estimated component means, mixing proportions, and patient counts.
- `component_interpretation.csv` — interpretation of the three latent headache-frequency groups.
- `final_model_assessment.csv` — final three-component model fit statistics.

Additional output files are retained in the supplied project package and can be added to this folder as the repository is finalized.
